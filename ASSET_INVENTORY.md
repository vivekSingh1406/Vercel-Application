The generated JPEG previews are in `public/media/`; no stock imagery or generated village photographs are used. Media retains embedded contributor credits (including Ajay Kumar Bais and other original overlay handles). The Swift extraction helper is optional development tooling, not part of the website runtime.

Asset preparation on macOS: `swift scripts/extract-assets.swift`, then `sips -r -90 public/media/village-5.jpg public/media/village-6.jpg`. The Swift helper extracts the original orientation; run each rotation only once per fresh extraction.

The videos are relatively large. The website loads only their posters initially and requests a video when a visitor opens it. For deployment, consider additional compressed copies while preserving these originals.
